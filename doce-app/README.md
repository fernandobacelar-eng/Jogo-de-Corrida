# Flauta Doce Guia

Aplicativo Android para aprender **flauta doce soprano** (digitação barroca).
Mesmas funções do Flauta Guia 2: afinador, digitações (25 notas, Dó4 a Dó6, com
meia-tampa e furos duplos), descobrir a nota, lições, músicas com partitura,
metrônomo e ritmo, e leitura de partitura.

As notas aparecem como escritas para flauta doce soprano; o som real é uma
oitava acima, e a detecção pelo microfone já leva isso em conta.

As imagens de `www/img/onb-*.png`, `inicio-hero.png` e o logotipo são
**provisórias** (geradas por `tools/gerar-provisorias.cjs`).

APK: https://github.com/fernandobacelar-eng/Jogo-de-Corrida/releases/download/flauta-doce/flauta-doce-guia.apk
