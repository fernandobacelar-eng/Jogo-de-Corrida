# Sax Guia

Aplicativo Android para aprender **saxofone alto (Mi♭)**. Mesmas funções do
Flauta Guia 2 e do Flauta Doce Guia: afinador, digitações (32 notas, Si♭3 a Fá6,
com chave de oitava, chaves de palma, laterais e dos mínimos), descobrir a nota,
lições, músicas com partitura, metrônomo e ritmo, e leitura de partitura.

As notas aparecem como escritas para sax alto; o som real é uma sexta maior abaixo.
Para afinar, o app usa o Fá♯5 escrito (soa como o Lá de 440 Hz).

Imagens e logotipo **provisórios** (`tools/gerar-provisorias.cjs`).

APK: https://github.com/fernandobacelar-eng/Jogo-de-Corrida/releases/download/sax/sax-guia.apk
